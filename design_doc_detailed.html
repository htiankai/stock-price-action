2. 分析引擎模块 (Analysis Engine)

2.1 支撑阻力位算法

参数默认值说明
window20局部高低点窗口大小
min_touches2最小触碰次数
volume_threshold1.5成交量放大倍数

算法流程

  1. 计算 window 周期内的局部最高价/最低价
  2. 筛选触碰次数 ≥ min_touches 的价格水平
  3. 结合成交量确认支撑/阻力强度
  4. 输出按强度排序的价格列表

2.2 趋势线算法

类型算法输出
上升趋势线连接 ≥ 3 个逐步抬升的低点斜率、角度、方程
下降趋势线连接 ≥ 3 个逐步下降的高点斜率、角度、方程
通道线趋势线 + 平行线上轨、下轨

2.3 技术指标参数

指标参数配置周期
MA5短期均线5
MA10短期均线10
MA20中期均线20
MA60长期均线60
MACD12, 26, 9快线/慢线/信号线
RSI14超买超卖
布林带20, 2周期/标准差倍数

2.4 形态识别规则

形态条件信号
Pin Bar 影线 ≥ 实体2倍，出现在关键位 反转信号
吞没形态 后一根K线实体完全包裹前一根 反转信号
锤子线 下影线 ≥ 实体2倍，在下跌后 底部反转
黄昏星 三根K线组合，出现在上升后 顶部反转
十字星 开盘≈收盘，影线较短 犹豫/中继

3. 信号生成模块 (Signal Generator)

3.1 信号类型

信号类型说明优先级
BREAKOUT突破支撑/阻力高
BREAKDOWN跌破支撑高
PATTERN形态识别信号中
CROSS均线金叉/死叉中
OVERBOUGHTRSI超买低
OVERSOLDRSI超卖低

3.2 信号结构

Signal {
    type: str              # 信号类型
    direction: str         # "long" / "short" / "neutral"
    strength: int          # 强度 1-5
    price: float           # 触发价格
    target: float          # 目标价格
    stop_loss: float       # 止损价格
    pattern_name: str       # 形态名称(如有)
    timestamp: datetime    # 信号时间
    metadata: dict         # 附加信息
}

3.3 信号确认规则

信号需要满足以下条件才会输出：

  1. 突破需收盘价确认（非仅日内突破）
  2. 成交量放大 ≥ 1.2倍均量
  3. 形态信号需出现在关键支撑/阻力位
  4. RSI信号需结合趋势方向

10. 复权数据说明

为什么需要复权？

股票有分红、配送、增发等行为时，股价会产生跳空缺口。前复权/后复权可以消除这种缺口，使K线连续，方便技术分析。

复权类型参数值特点适用场景
前复权 qfq 以最新价格为基准，历史价格向下调整 技术分析（推荐）
后复权 hfq 以原始价格为基准，最新价格向上调整 长期投资分析
不复权 保持原始价格，有跳空缺口 简单查看

本系统默认使用前复权(qfq)，因为技术指标计算需要连续的K线数据。

11. 实时更新机制

11.1 轮询策略

数据类别轮询间隔缓存TTL说明
实时行情3-5秒0秒交易时段实时更新
分时数据30秒10秒交易时段
K线数据收盘后更新1天日K线不频繁变化

11.2 缓存失效策略

缓存写入条件

  • API请求成功返回数据
  • 数据时间戳 > 缓存时间戳
  • 数据量 ≥ 请求量

缓存失效条件

  • 超过TTL时间
  • 收到错误响应
  • 手动刷新触发

11.3 并发控制

策略参数说明
单股票请求-串行获取，避免频率限制
多股票请求asyncio并发最多5个并发连接
重试机制3次，间隔2秒网络抖动时自动重试
退避策略指数退避触发限流时自动降频
